# Decisions

Each entry: what was decided, why, and when. `VERIFY` items from the spec are marked as such once resolved.

## D1. Library majors (2026-11-08, M0)

The newest majors on npm at the time were TypeScript 7, NestJS 12, Prisma 7/8, Vite 8, Vitest 5, ESLint 10. We pinned to the previous, well-established majors instead:

| Area | Chosen | Newest available | Why |
|---|---|---|---|
| TypeScript | 5.9 | 7.0 | TS 7 is the native-compiler rewrite; NestJS decorator metadata and ts-jest support are not yet proven on it. |
| NestJS | 11 | 12 | Stable, matches spec "10+". |
| Prisma | 6.19 | 7.x / 8 rc | Prisma 7 changes client generation and config substantially; 6 is stable and documented. |
| Vite / Vitest | 6 / 3 | 8 / 5 | Vitest 5, jsdom 27+ and jest-dom 7 need Node 22; the dev machine has Node 20.19. |
| React | 18 | 19 | The spec says React 18. |
| ESLint | 9 | 10 | Plugin ecosystem (react-hooks, typescript-eslint) is verified on 9. |
| Zod | 4 | 4 | Current. |
| Tailwind | 4 | 4 | Current. |

Upgrade path: bump one major at a time behind CI once the ecosystem catches up. Docker images and CI use Node 22 (`.nvmrc`); local development works on Node >= 20.19.

## D2. ORM: Prisma (2026-11-08, M0)

The spec allows TypeORM or Prisma. We picked Prisma for schema-first migrations and generated types.

## D3. UI: shadcn/ui-style components + Tailwind 4 (2026-11-08, M0)

The components in `apps/web/src/components/ui/` are written by hand in shadcn/ui style (Radix primitives, `cva`, `tailwind-merge`) rather than generated by the shadcn CLI, so no interactive tooling is needed.

## D4. Python tooling: uv (2026-11-08, M0)

`uv` with a committed `uv.lock`. The Docker image copies the `uv` binary from the official image.

## D5. Object storage: SeaweedFS instead of MinIO for local dev (2026-11-08, M0)

The spec names MinIO, but the `minio/minio` and `minio/mc` images can no longer be pulled from Docker Hub or quay.io. We use `chrislusf/seaweedfs` (pinned tag) with its S3 gateway on port 9000. Credentials come from `infra/seaweedfs/s3.json` (local dev only). The app talks plain S3, so any S3-compatible store works in other environments. Buckets are created by the API at startup (from M2), not by an init container.

## D6. Same-origin API in the browser (2026-11-08, M0)

The web app calls `/api/*`, and the Vite dev server proxies to NestJS. Cookies (the refresh token) stay first-party and `SameSite=Strict` works without cross-site CORS. CORS is still restricted to `WEB_ORIGIN`.

## D7. Local Postgres on host port 5433 (2026-11-08, M0)

Port 5432 is often taken on dev machines. Override with `POSTGRES_HOST_PORT`. One Postgres server hosts three databases: `mtj` (API), `mtj_langgraph` (checkpoints) and `mtj_test` (e2e tests).

## D8. Shared contracts as zod schemas (2026-11-08, M0)

`packages/contracts` holds zod schemas and inferred TS types for request/response bodies. The web app uses them for forms and typing. The API validates with class-validator DTOs (spec requirement) and publishes OpenAPI at `/docs` in non-production. DTOs and contracts are kept in sync by the API e2e tests, which assert response shapes.
